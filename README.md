# Python Task Manager

My first Python task manager project.

## Features

- Add tasks
- View all tasks
- View pending tasks
- View completed tasks
- Remove tasks
- Mark tasks as completed
- Save tasks to a JSON file
- Load tasks automatically

- Functions
- Lists
- Dictionaries
- Loops
- User input validation
- Python's datetime module
